# capswriter-client

CapsWriter-Offline **客户端** PyPI 包。

- 命令：`capswriter-client`
- 初始化：`capswriter-client-init`（在当前目录生成 `config_client.py`、热词模板）

完整安装步骤见：[docs/UV安装说明.md](../../docs/UV安装说明.md)

```powershell
uv tool install capswriter-client
# 或 Git：
uv tool install "git+https://github.com/Nurdich/CapsWriter-Offline.git@island#subdirectory=packages/capswriter-client"
```
